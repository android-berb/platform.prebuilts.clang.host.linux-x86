# Clang android prebuilts host linux x86

## Fork the googlesource repo from github
https://github.com/android-berb/platform.prebuilts.clang.host.linux-x86.git
or
## Forked repo:
https://android.googlesource.com/platform/prebuilts/clang/host/linux-x86.git
## Configure permissions to the forked repo

## Select a branch in the prebuilts repo for the
## wich contains the clang version we need
Ex. last clang 14:
    * android14-qpr3-s15-release
## Create a new branch from the selected above
## In this branch we clean the not needed versions
## and the stable dirs.
## NOTE: Can be done directly from github by creating
##       a new branch from the selected above.

## Clone shallow branch
##A. Clone the new branch if created from github
git clone --depth 1 -b clang-14-r450784e-a14-x86 repo_url
cd platform.prebuilts.clang.host.linux-x86
##B. Clone original branch and create the new locally
git clone --depth 1 -b android14-qpr3-s15-release repo_url
cd platform.prebuilts.clang.host.linux-x86
git checkout -b clang-14-r450784e-a14-x86 android14-qpr3-s15-release

## Now we should are in the cloned repo
## and in the new branch for both above cases
## Now we want to remove not needed dirs
rm -r clang-xxxxx
rm -r clang*stable llvm*stable
git add -A
git commit -m "Remove not needed versions"
git push origin clang-14-r450784e-a14-x86

## Adding other branches locally:
git fetch --depth 1 origin android12L-d2-s8-release
git checkout -b clang-12-r416183b-a12-x86 origin/android12L-d2-s8-release
## Repeat the clean versions step
